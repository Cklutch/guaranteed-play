# QB Elite Season Age Study

This study measures each age's share of elite QB finishes. It does not use average PPG by age.

Rate % = players at that age inside Top N QB slots / all Top N QB slots.

## Data Source

- Source: nflverse-data GitHub releases: stats_player + rosters
- Releases: stats_player, rosters
- Timeline: 2023-2025
- Seasons used: 3
- Scoring: Half PPR
- Player-seasons analyzed: 1,783
- Cache file: `case_studies\data\qb_rb_te_wr_elite_age_player_seasons_half_ppr.csv`

## Peaks

- Peak Age for Top 20 Rate: Age 28 (13.33%)
- Peak Age for Top 15 Rate: Age 27 (15.56%)
- Peak Age for Top 12 Rate: Age 27 (16.67%)
- Peak Age for Top 6 Rate: Age 24 (16.67%)
- Peak Age for Top 3 Rate: Age 27 (22.22%)
